BACKGROUND MUSIC SETUP

To enable the music button:
1. Choose an MP3 you own or have permission to use.
2. Rename the file to wedding-melody.mp3.
3. Place it in this folder: public/music/wedding-melody.mp3
4. Restart the Vite dev server if needed.

The website will try to play this file only after a guest clicks the music button. Browsers usually block autoplay until the user interacts with the page.
